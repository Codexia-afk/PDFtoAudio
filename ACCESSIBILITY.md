# Accessibility Conformance Statement — PDFtoAudio

PDFtoAudio is built to meet **WCAG 2.1 Level AA** standards, empowering visually impaired users, auditory learners, non-native speakers, and individuals with dyslexia.

## Key Accessibility Features

### 1. Dyslexia-Friendly Typography
* Includes standard support for **OpenDyslexic**, a font designed to mitigate common reading errors and visual distortion for readers with dyslexia.

### 2. High Contrast Theme
* A high-contrast display mode (`body.high-contrast`) providing clear color distinction and maximum readability.

### 3. Word & Sentence Karaoke Highlighting
* Synchronized visual sentence highlighting with page-level indicators as audio plays.

### 4. Full Keyboard Navigation
* All interactive buttons, tabs, dropdowns, dropzones, and controls feature visible focus outlines (`:focus-visible`) and complete keyboard navigation.

### ⌨️ Keyboard Shortcuts Map
| Key | Action |
| :--- | :--- |
| `Space` / `K` | Play / Pause Audio |
| `M` | Toggle Mute / Unmute |
| `?` | Open Accessibility Settings Drawer |

### 5. Screen Reader Optimization
* All player controls, file upload zones, and text readers incorporate semantic HTML5 tags and `aria-label` / `aria-live` attributes.
